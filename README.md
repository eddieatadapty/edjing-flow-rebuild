# edjing Mix Growth Audit

**Live → https://eddieatadapty.github.io/edjing-flow-rebuild/**

Five ideas to turn more edjing Mix users into subscribers, each built into a clickable version of edjing Mix's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the answers you collect | +10–20% CR to purchase |
| 02 | A first mix before the paywall | +5–15% CR to purchase |
| 03 | Proof before the price | +5–15% CR to purchase |
| 04 | Make the annual saving impossible to miss | +10–15% ARPU |
| 05 | Catch the people who close the paywall | +10–15% ARPU |

Every price, rating and feature comes from edjing Mix's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for edjing Mix. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
